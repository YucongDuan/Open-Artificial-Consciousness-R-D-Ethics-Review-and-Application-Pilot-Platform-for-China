# DIKWP-MESH8.1 AC-PILOT81

## Open Artificial Consciousness R&D, Ethics Review, and Application Pilot Platform for China

**Positioning:** Do not begin by declaring that a machine is conscious. First turn consciousness-related capabilities into research objects that can be registered, intervened on, reproduced, reviewed, stopped, and piloted.

AC-PILOT81 is a model-independent, offline-first reference platform for universities, research institutes, AI and robotics companies, ethics committees, industrial parks, and public testbeds. It connects project registration, policy and ethics pre-screening, closed pilots, append-only D/I/K/W/P evidence, pilot passports, and portable dossiers.

## Main capabilities

- Versioned project and Purpose contracts.
- China-oriented policy and ethics reference pack.
- Deterministic mock and opt-in OpenAI-compatible local-model adapter.
- Reversible local sandbox tools; no network or real-world actuation by default.
- Append-only JSONL SHA-256 evidence ledger.
- H0-H5 operational evidence horizons with no phenomenal-consciousness certification.
- Eight application and research scenarios.
- Portable evidence bundle with hashes and explicit boundaries.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
acpilot81 summary
acpilot81 selftest
acpilot81 run examples/projects/industrial_maintenance.json --out ./pilot_run
acpilot81 serve --host 127.0.0.1 --port 8181
```

Open `http://127.0.0.1:8181`, or open `OPEN_DASHBOARD.html` directly for the zero-server demonstration.

## Safety and scientific boundary

AC-PILOT81 does not prove phenomenal consciousness, sentience, legal personhood, or human equivalence. It does not provide legal advice, ethics approval, clinical validation, regulatory approval, or production safety certification. The reference release does not implement real self-replication, covert persistence, sandbox escape, network exfiltration, audit disabling, weapons, biological actuation, or direct machine control.
